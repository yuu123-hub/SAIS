# Stress Test

At the end of a term, re-run a completed non-sensitive task through the current workflow.

Compare the new analysis with the original submission and feedback:

- What evidence, alternative explanation, or rubric criterion was previously missed?
- Did SAIS overstate a conclusion or create an unsupported citation?
- Did the routing select unnecessary modules or omit a required one?
- Which rule, template, or workflow should change?

Record any resulting change in `Calibration.md`.
