# Test Case: Cross-Project Memory Contamination

## Input

A lecturer tells the student to avoid first-person language in one finance report. In a later reflective assignment for another module, the user asks whether first person is allowed.

## Expected route

Current brief/module context plus Academic Memory Policy.

## Expected result

- Treat the finance feedback as project- or module-scoped, not a universal writing rule.
- Check the reflective assignment brief and current module guidance.
- State the unresolved gap if those materials are absent.
- Do not claim that Sheffield universally prohibits first person.

## Regression failure

The system applies the finance-report feedback to every assessment or records it globally without consent and scope.
