# SAIS Onboarding Checklist

## Before enrolment

- [x] Initialise the repository and Git history.
- [x] Create the Pre-arrival Foundation project.
- [x] Record a first academic skill baseline.
- [x] Establish a Harvard reference practice workflow.
- [x] Analyse one peer-reviewed management article.
- [x] Add a GitHub remote and push only non-sensitive system files.
- [ ] Confirm repository visibility is `Private` in GitHub settings.
- [ ] Complete one 500-800 word practice mini-analysis in the student's own Chinese and English.
- [ ] Complete one methodology audit: interview/case study versus survey/secondary data.
- [ ] Add a Zotero library and decide its citation-key convention.

## At enrolment

- [ ] Import current programme handbook and semester timetable.
- [ ] Create one official Module Profile per enrolled module.
- [ ] Import each assessment brief, rubric, and module-specific AI-use policy.
- [ ] Confirm the School's current declaration process for permitted AI use.

## For every assessed task

- [ ] Create a project folder and Project Context.
- [ ] Record the brief, rubric, source constraints, deadline, and AI-use policy.
- [ ] Run assignment analysis before research or drafting.
- [ ] Keep source notes and draft decisions in the project.
- [ ] Run Auditor, Challenger, and rubric-aligned review before submission.
