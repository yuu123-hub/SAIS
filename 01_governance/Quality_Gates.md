# Quality Gates

| Gate | Question | Action if not met |
| --- | --- | --- |
| Integrity | Are sources, quotations and data genuine and attributable? | stop and request verification |
| Evidence | Do material claims have appropriate support? | add a Gaps list and research plan |
| Reasoning | Does the conclusion follow; are alternatives considered? | revise argument map |
| Academic communication | Are fact, analysis and suggestion distinct; is tone appropriate? | revise for clarity and British English |
| Task alignment | Does the output answer the brief and rubric? | return to assignment analysis |
