# Workflow: Distinction and Career Evidence Loop

## Purpose

Turn verified module requirements, rubric evidence, marker feedback, and completed work into a disciplined improvement loop and safe career evidence without reducing learning to a score-chasing checklist.

## Task Context

A current module, an assessed project, or released feedback. The relevant authority is the current handbook, rubric, brief, and assessment-specific AI rule, not generic SAIS guidance.

## Required Inputs

- Official module handbook or module guide when available.
- Current brief, rubric, deadline, and AI-use rule for an assessment.
- Draft/plan and verified source records for an active assessment.
- Official mark and feedback for the feedback stage.
- A career target only when preparing an optional career evidence card.

## Method

1. **Module contract:** import only verified handbook/rubric facts into `Module_Performance_Contract.md`: learning outcomes, assessment components/weights, dates, distinction descriptors, AI boundaries, and open questions.
2. **Assessment ledger:** for each active assessed task, create `Assessment_Evidence_Ledger.md`. Map each material criterion to a claim, theory, verified evidence, alternative view, draft location, and unresolved gap.
3. **Criticality check:** apply Auditor and Challenger. For relevant Management/IB work, test comparison, evidence-to-conclusion fit, alternatives/limits, managerial implications, and case/country transferability.
4. **Submission gate:** use the ledger alongside `Submission_Readiness.md`; do not call a criterion evidenced merely because it is mentioned.
5. **Feedback intelligence:** when feedback arrives, record marker words, diagnose the category, select one observable next behaviour, and test it in the next task. Keep feedback project-scoped unless promotion to global memory is consented and justified.
6. **Career evidence:** after a strong, completed project, produce a public-safe abstraction using `Academic_to_Career_Evidence_Card.md`. Exclude confidential material and never republish assessed prose.
7. **Decision record:** use `Option_and_Dissertation_Decision_Record.md` for optional-module or dissertation choices. Review when official availability, assessment details, or career priorities change.

## Output

- Current Module Performance Contract status.
- Criterion-to-evidence map and highest-impact gap.
- One measurable improvement behaviour after feedback.
- Optional, safe career card or a deferred decision record.

## Gaps

Record unissued handbook/rubric details, unknown AI rules, unverified evidence pages, absent feedback, confidential material, and any choice that depends on provisional module availability.

## Next Action

Import the smallest missing authoritative document, or update the single ledger row with the highest effect on task alignment.
