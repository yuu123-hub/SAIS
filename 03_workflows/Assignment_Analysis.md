# Workflow: Assignment Analysis

## Task Context

Assignment brief, module profile, rubric, deadline, word limit, and known source constraints.

## Required Inputs

The full brief and rubric. If either is absent, analyse what is available but label the missing item as a blocking or non-blocking gap.

## Method

1. Extract deliverable, command words, topic boundaries, word/time limit, assessment criteria, and required evidence.
2. Convert each assessment criterion into a visible success condition.
3. Identify concepts, theories, cases, and evidence categories—not a preselected conclusion.
4. Produce a research plan and a provisional outline with a counterargument or limitation section where suitable.
5. Identify decisions that require lecturer clarification.

## Output

Brief analysis, success conditions, research questions, evidence plan, outline, risks, and next action.

## Gaps

List absent rubric, source requirements, module guidance, case materials, or AI-use policy explicitly.

## Next Action

Request sources, confirm an interpretation, or start a bounded literature search.
