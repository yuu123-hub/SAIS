# Workflow: Assessment and Distinction Review

## Task Context

An assessed draft or plan, its project context, and the current authoritative assessment materials.

## Required inputs

Draft or plan; current brief; rubric or marking criteria; source list; and an Assessment Evidence Ledger where a project has begun. Without a rubric, review against general postgraduate standards and explicitly label this limitation.

## Method

1. Map each criterion to evidence in the draft or plan.
2. Update or create an Assessment Evidence Ledger that links each material criterion to core claims, theory, evidence, counter-evidence, draft location, and a current gap.
3. Diagnose description, theory application, evidence quality, argument coherence, independent judgment, structure, and task-relevant implications.
4. Identify the one to three highest-impact changes likely to improve the work.
5. Do not invent a numerical grade. Give a rubric-qualified readiness judgement: `not assessable`, `below stated standard`, `approaching stated standard`, or `evidence of stated standard`.

## Output

Strengths; criterion-by-criterion gaps; priority revision plan; source risks; next action.

## Gaps

Record absent rubric language, incomplete draft sections, unverifiable sources, and any criterion that cannot be assessed.

## Next Action

Apply the highest-impact revision or obtain the missing authoritative assessment material.
