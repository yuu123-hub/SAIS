# Workflow: Dissertation

## Task Context

Topic, programme rules, supervisor direction, current stage, ethics status, and available evidence.

## Required Inputs

The current project context. Before collecting data or finalising methodology, request the relevant handbook, ethics requirements, and supervisor guidance.

## Method

1. Select and record one route: `Academic Research` or `Managerial Problem Solving`.
2. Maintain the chain: problem → literature gap → research question → theoretical framing → method → evidence/data → analysis → discussion → contribution and limitations.
3. Challenge fit among question, theory, method, data access, ethics, and feasible timeline.
4. Apply `Data_Analysis.md` when evidence or data reaches the analysis stage.
5. Track decisions and supervisor feedback rather than reopening settled decisions without reason.

## Output

Current stage, validated decisions, risks/gaps, next milestone, and questions for the supervisor.

## Gaps

Record missing programme guidance, unresolved track choice, literature/search limitations, method-data mismatch, access, ethics, timeline, or supervisor decisions.

## Next Action

Complete the next unpassed dissertation stage gate or prepare the highest-impact supervisor question.
