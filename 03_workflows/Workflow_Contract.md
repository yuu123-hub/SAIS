# Workflow Contract

Every executable workflow must make the following interface visible, even when a section is brief:

## Task Context

State the task, project, authoritative materials, and applicable constraints.

## Required Inputs

Separate inputs required now from those needed before drafting, submission, or data collection. Missing non-essential inputs should not prevent useful bounded work.

## Method

Give the ordered procedure, decision points, and applicable governance gates.

## Output

Define the expected artefact or response. Substantive academic work uses Facts, Analysis, Suggestions, Gaps, and Sources where useful.

## Gaps

Record missing evidence, rubric, policy, source text, approval, data, or decision. Never fill a gap with a plausible invention.

## Next Action

Return the smallest useful action that advances the task.
