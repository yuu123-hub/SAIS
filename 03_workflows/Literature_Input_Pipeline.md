# Workflow: Literature Input Pipeline

1. **Collect** — retain original source, legal access information, and metadata.
2. **Convert** — OCR a scanned PDF when needed; preserve page numbering and section headings.
3. **Pre-process** — state the project question/hypothesis and expected relevance before reading.
4. **Extract** — record methods, findings, limitations, evidence, and quotations only with verified locations.
5. **Index** — create a Reading Note and Evidence Record.
6. **Link** — connect it to the relevant theory, concept, argument, gap, or project.

Low-weight sources may generate questions but should not carry a core factual claim without stronger corroboration.
