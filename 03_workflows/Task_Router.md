# Task Router

## Classification rules

| Task signal | Primary workflow | Add-ons |
| --- | --- | --- |
| new assignment, create project, start coursework | Project Lifecycle | Project Context, project initializer |
| ready to submit, final check | Project Lifecycle submission check | Submission Readiness, Auditor, Assessment Review |
| brief, rubric, assessment question | Assignment Analysis | Assessment Review, Argument Map |
| report, essay, case study | Assignment Analysis or Draft Review | Management analysis lens |
| group report, group presentation, team assignment | Group Project | shared Project Context, contribution and integration records |
| exam revision, reflective assignment | Exam and Reflection | official learning outcomes or brief |
| one paper or article | Literature Analysis | Reading Note, Evidence Record |
| find papers, literature search/review, evidence base | Literature Search and Synthesis | Search Log, Literature Synthesis |
| research question, method, coursework research proposal | Research Design | Assignment Analysis when assessed, Literature Gap, Methodology Audit |
| dataset, statistics, regression, survey results, coding, themes | Data Analysis | Data Analysis Plan, quantitative or qualitative result record |
| dissertation proposal or dissertation research idea | Dissertation | Dissertation Status, chosen dissertation track |
| dissertation ethics, dissertation data collection, dissertation supervisor | Dissertation track | Dissertation Status, Feedback Log |
| presentation | Presentation | Assessment Review |
| supervisor feedback, lecturer feedback, meeting notes | Supervisor Meeting | Feedback Log, Growth Log |
| Chinese explanation, Chinese-to-English, improve academic English | Chinese-to-English Drafting | AI-use policy, source verification |
| skills/readiness/career | Pre-arrival and Growth | Skill Gap Tracker |
| module handbook, syllabus, module setup | Module Onboarding | Module Profile, Module Source Register |

## Minimum context by task

Never block a useful first response for a nonessential missing item. Instead identify whether it is: `required now`, `needed before drafting`, or `needed before submission/data collection`.
