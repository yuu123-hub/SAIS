# 第一次 Coursework 使用 Checklist

**模板狀態：Prepared, not executed。此清單給零技術背景使用者；不需要理解 Git、YAML、JSON、Python、Runtime 或 repository。**

## 收到作業時

1. 建立新的 assignment-specific 對話。
2. 上傳 assignment brief。
3. 上傳 rubric。
4. 上傳 learning outcomes 或 module handbook 的相關頁面。
5. 上傳 assessment-specific AI policy。
6. 暫時不要要求撰寫正文。
7. 先執行 Brief Analysis。

## 開始閱讀時

1. 上傳或提供合法取得的來源。
2. 要求 Source Analysis。
3. 檢查來源、頁碼和限制。
4. 建立 claim-evidence map。
5. 不得引用 SAIS 文件作為學術來源。

## 規劃時

1. 產生 outline。
2. 映射 rubric。
3. 記錄缺少的 evidence。
4. 確認 AI-use boundary。
5. 使用者批准後才進下一階段。

## 修訂時

1. 上傳自己的 draft。
2. 執行 Auditor。
3. 執行 Challenger。
4. 執行 Citation Integrity Check。
5. 執行 Claim-Evidence Check。
6. 優先修正 Blocking 和 Major 問題。

## 提交前

1. 執行 Submission Audit。
2. 檢查 reference list。
3. 檢查 AI declaration。
4. 檢查檔名、格式、截止時間與 portal。
5. 使用者親自確認最終稿。
6. SAIS 不保證成績，也不代替提交責任。

## 使用後

1. 複製 `01_COURSEWORK_USAGE_LOG_TEMPLATE.md`。
2. 填寫真實結果。
3. 發現具體問題時才建立 Issue Report。
4. 收到正式 feedback 後填寫 Feedback Evidence Log。

正式作業與私人資料應留在 assignment-specific 私人工作區，不要直接放入此公共模板目錄。
