# SAIS Stage A Coursework Validation Toolkit

**Stage A status: Prepared, not executed.**

本目錄只提供空白模板，用來收集真實 coursework 的使用證據；目的不是證明 SAIS 一定有效，也不是預先判定 Runtime 有必要。

## 使用原則

1. 每份真實 coursework 建立一份 [Usage Log](01_COURSEWORK_USAGE_LOG_TEMPLATE.md) 副本。
2. 只有遇到具體、可描述的問題時，才建立 [Issue Report](02_ISSUE_REPORT_TEMPLATE.md)。
3. Lecturer 或 supervisor feedback 必須是原文或準確轉錄，不得推測或補寫。
4. 至少完成 2–3 份真實 coursework 後，才使用 [Stage A Review](06_STAGE_A_REVIEW_TEMPLATE.md)。
5. [Runtime Trigger Scorecard](05_RUNTIME_TRIGGER_SCORECARD.md) 只能輔助決策，不能自動批准 Runtime。
6. 正式作業、私人資料、回饋原文與來源材料不得直接放在本公共模板目錄；填寫後的副本應置於 assignment-specific 私人工作區。
7. 評估結果不得宣稱保證 Distinction 或任何特定成績。
8. 不得把本目錄上傳為 ChatGPT Project Knowledge；它是本地驗證模板，不是知識包。

## 建議使用順序

1. [07_FIRST_COURSEWORK_CHECKLIST.md](07_FIRST_COURSEWORK_CHECKLIST.md)
2. [01_COURSEWORK_USAGE_LOG_TEMPLATE.md](01_COURSEWORK_USAGE_LOG_TEMPLATE.md)
3. [03_CHATGPT_PROJECT_DEPLOYMENT_LOG.md](03_CHATGPT_PROJECT_DEPLOYMENT_LOG.md)
4. [02_ISSUE_REPORT_TEMPLATE.md](02_ISSUE_REPORT_TEMPLATE.md)，僅在具體問題出現時建立。
5. [04_FEEDBACK_EVIDENCE_LOG.md](04_FEEDBACK_EVIDENCE_LOG.md)，僅在收到真實正式回饋後填寫。
6. [05_RUNTIME_TRIGGER_SCORECARD.md](05_RUNTIME_TRIGGER_SCORECARD.md) 與 [06_STAGE_A_REVIEW_TEMPLATE.md](06_STAGE_A_REVIEW_TEMPLATE.md)，僅在 evidence 足夠時使用。
