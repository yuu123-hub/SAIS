## Category

選擇一項或多項：

- Missing input handling
- Wrong routing
- Missing module
- Stale rule
- Source fabrication
- Page fabrication
- Citation mismatch
- Claim-evidence weakness
- Context loss
- Version mismatch
- Deployment problem
- Template problem
- Quality-control failure
- Usability problem

## 安全提醒

Evidence 必須是最小化、可授權且可安全保存的摘錄或位置描述。Root cause 在未證實前只能標為 Hypothesis 或 Unknown；不得把單一 issue 自動升級為 Canonical rule 改動。
