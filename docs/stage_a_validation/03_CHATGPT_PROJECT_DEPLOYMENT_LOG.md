## 每次更新程序

```text
1. 記錄現有版本。
2. 移除全部舊版 SAIS Knowledge 文件。
3. 更新 Project Instructions。
4. 上傳新版 12-file Pack。
5. 確認沒有新舊版本共存。
6. 執行 Smoke Test。
7. 記錄結果。
```

不要求比較 checksum 或編輯 JSON。任何 temporary assignment file 都應在 assignment-specific policy 與機密要求允許時才上傳，並在不需要時移除。
