## 規則

1. 不得虛構 feedback。
2. 不得把自己的猜測寫成 marker 意見。
3. 單次 feedback 不一定足以修改 Canonical rule。
4. 個別 assessment 要求不得自動一般化為所有 coursework 規則。
5. 敏感或私人 feedback 不得放入公開 export；應保存於合適的私有工作區。
