# Academic Memory Policy

## Purpose

Allow SAIS to learn across tasks without treating one project, marker, context, or provisional decision as a universal rule.

## Memory scopes

| Scope | Examples | Storage | Reuse rule |
| --- | --- | --- | --- |
| Project | brief interpretation, argument decision, source relevance, supervisor feedback for one dissertation | `05_projects/<project>/` | use only in that project unless explicitly promoted |
| Module | official learning outcomes, module AI policy, recurring lecturer direction | `02_institution/modules/<module>/` | use only for that module and academic year |
| Global personal | recurring writing difficulty, stable research interest, demonstrated learning preference | `06_memory/` | use across tasks only within recorded boundaries |
| Institutional | verified programme or School rules | `02_institution/` | use according to provenance and freshness; current assessment rules override |

## Promotion rule

Do not promote a project observation into global memory automatically. Promotion requires:

1. identifiable provenance;
2. a stated scope and boundary;
3. user consent;
4. either repeated evidence or an explicit reason why one observation is sufficiently general; and
5. a review date or condition for revision.

## Feedback rule

- Preserve direct feedback separately from the student's or SAIS's interpretation.
- A marker preference is not a University rule.
- A weakness in one genre is not automatically a weakness in all writing.
- Superseded feedback remains traceable but must not silently control later work.

## Retrieval rule

When loading memory, prefer the narrowest applicable scope:

`current project → current module/year → verified institution → consented global personal memory`

If two memories conflict, present the conflict and use the more authoritative, current, and task-specific record.
