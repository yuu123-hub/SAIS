# Assessment Evidence Ledger

> Keep this in the project `notes/` folder. Its job is to show how each rubric requirement is evidenced in the work, not to create a superficial checklist or predict a grade.

## Ledger rules

- Cite only a source you have checked; use `Unknown` rather than guessing a page number.
- A source record is not enough: state how the source supports, qualifies or challenges the claim.
- A rubric row may map to several paragraphs, but every major draft section should have a visible rubric purpose.
- If the evidence does not support the claim, narrow the claim or obtain better evidence; do not write around the gap.
