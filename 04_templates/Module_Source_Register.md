## Rules

- Assessment-specific instructions override general module guidance for that assessment.
- Current official material overrides older material unless the current document explicitly preserves it.
- Direct lecturer clarification must be recorded with date and exact scope.
- Store licensed or access-controlled originals in `source_materials/`; Git ignores that directory by default.
