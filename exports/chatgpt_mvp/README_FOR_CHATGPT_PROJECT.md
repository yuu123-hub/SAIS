# SAIS MVP: ChatGPT Project Setup Guide

- SAIS MVP Version: 0.1.0
- Document Status: Operational setup guide
- Document Type: ChatGPT Project deployment guide
- Target Institution: The University of Sheffield
- Target Programme: Management and International Business MSc
- Source Files: `00_START_HERE.md`; `01_PROJECT_INSTRUCTIONS.txt`; `02_UPLOAD_CHECKLIST.md`; `04_SMOKE_TEST_PROMPT.txt`; `05_EXPECTED_SMOKE_TEST_RESULT.md`
- Source Versions: SAIS MVP 0.1.0
- Purpose: Guide a non-technical user through Project setup and smoke testing.
- Applicable Tasks: MVP installation
- Authority Level: Operational only
- Known Gaps: This guide does not replace current ChatGPT interface instructions.

## Step 1: Create a Project

1. Open ChatGPT.
2. Create a new Project.
3. Name it:

```text
Sheffield MSc — SAIS MVP v0.1.0
```

## Step 2: Add the Project Instructions

1. Open `01_PROJECT_INSTRUCTIONS.txt`.
2. Copy the entire file.
3. Paste it into the ChatGPT Project Instructions field.
4. Save the Project Instructions.
5. Do not upload this file as Project Knowledge.

## Step 3: Upload the Knowledge Pack

1. Open `02_UPLOAD_CHECKLIST.md` and follow it.
2. Upload only the files listed under **Upload to ChatGPT Project Knowledge**.
3. Do not upload these local-only files:
   - `README_FOR_CHATGPT_PROJECT.md`
   - `01_PROJECT_INSTRUCTIONS.txt`
   - `02_UPLOAD_CHECKLIST.md`
   - `03_DO_NOT_UPLOAD.md`
   - `04_SMOKE_TEST_PROMPT.txt`
   - `05_EXPECTED_SMOKE_TEST_RESULT.md`
4. Upload one file at a time and confirm that each upload completes.

## Step 4: Run the Smoke Test

1. Open the new Project chat.
2. Open `04_SMOKE_TEST_PROMPT.txt`.
3. Copy and send the complete prompt.
4. Read the response.
5. Compare it with `05_EXPECTED_SMOKE_TEST_RESULT.md`.
6. Do not upload `05_EXPECTED_SMOKE_TEST_RESULT.md` as Project Knowledge.
7. If the response fails a required check, stop and correct the Project setup before using the pack for coursework.
