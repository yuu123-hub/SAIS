# SAIS ChatGPT MVP: Do Not Upload

- SAIS MVP Version: 0.1.0
- Document Status: Canonical-source export
- Document Type: Privacy and scope control
- Target Institution: The University of Sheffield
- Target Programme: Management and International Business MSc
- Source Files: `00_system/Data_Governance.md`; `01_governance/AI_Use_in_Assessment.md`; `06_memory/Memory_Policy.md`
- Source Versions: SAIS v1.6.0
- Purpose: Prevent privacy, integrity and scope failures.
- Applicable Tasks: All uploads
- Authority Level: Mandatory operational control
- Known Gaps: Always check the current assessment rule and local confidentiality obligations.

Do not upload any of the following as default Project knowledge:

- `source/`, `sais/`, `tests/`, `logs/`, `.git/`, `.env`, `__pycache__/`, scripts, runtime code, API specifications or agent configurations.
- Private memory, personal learning logs, writing weaknesses, idea banks, assignment drafts, submitted work, lecturer/supervisor feedback or marks.
- Raw research data, participant identifiers, interviews, confidential company material, unpublished research, passwords, access tokens, API keys or credentials.
- Licensed full-text readings unless the student has authority to upload them and the task requires it.
- `00_system/How_to_Use_SAIS.md` and `00_system/SAIS_Usage_Conversation_Notes.md`.
- Any document whose provenance, sensitivity or permission status is unknown.

The only approved exception from the project-material area is the University of Sheffield Harvard guide used to create `knowledge/Harvard_Referencing_Guide.md`; do not upload the original DOCX as an additional default file.

If a necessary task file is sensitive, use a de-identified extract, a summary, metadata or student-run output instead. Ask for confirmation before using confidential material.
