## Authority and freshness

The source guide states that this is the Harvard style supported by the University of Sheffield and that referencing guidance is updated regularly. Before a final submission, check the University Library referencing page: <https://sheffield.ac.uk/study-skills/writing/reference-proof/reference>.

## Core rules

- Harvard is an author-date system: cite the source in the text and provide full details in an alphabetical reference list.
- Cite quotations and a specific part of a source with a verified page number. Where pages are unavailable, use a verified paragraph, section or other location only as the guide permits.
- Paraphrasing and summarising still require citation. Paraphrase the meaning rather than changing a few words.
- Avoid secondary referencing where the primary source is available. If it is not, make clear which source was read and follow the guide's `cited in` treatment.
- Distinguish same-author/same-year works using lower-case letters consistently in text and the reference list.
- Use `and` for two or three authors; for four or more authors, use the first author followed by italicised `et al.` as specified by the guide.
- Use the title where no author is available and `no date` only when a date cannot be found.
- Reference-list entries are alphabetical. Keep author/date distinctions consistent; list multiple works by the same author chronologically.

## Reference verification

Before finalising a reference, check the source type, author/corporate author, date, title, publication/container details, edition where relevant, pages/volume/issue where relevant, and DOI or URL/access date where relevant. For a DOI, follow the current Sheffield guide's treatment; do not guess a DOI or turn an unverified URL into a reference.

## When this summary is insufficient

Consult the current full University guide for less common source types, legal materials, datasets, media, images, standards, unpublished material, GenAI-related work or any example not covered here. A module or assessment may give a more specific required format; that instruction controls.
