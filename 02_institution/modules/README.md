# Module Profiles

Create one directory per official module code only after you receive a current University of Sheffield handbook, module guide, or assessment documentation.

Use [Module_Profile.md](../../04_templates/Module_Profile.md) and record the source URL or filename, date received, academic year, learning outcomes, assessment details, rubric, required reading, and permitted AI use.

Before those documents are issued, use [MIB_2026_Official_Programme_Reference.md](../MIB_2026_Official_Programme_Reference.md) as programme-level context only. Do not create guessed module codes or assessment rules.
