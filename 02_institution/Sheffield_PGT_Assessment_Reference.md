# Sheffield Postgraduate Taught Assessment Reference

## Verified general reference

The University’s *Studying in the UK: What To Expect from Your Course* material presents the following general postgraduate taught master’s bands:

| Mark | General classification |
| ---: | --- |
| 70–100 | Distinction |
| 60–69 | Merit |
| 50–59 | Pass |
| 0–49 | Fail |

The same source states that students should check with their department for specific guidelines and explains that higher grades require moving beyond description to critical analysis.

## SAIS use rule

Use this only as a general institutional reference. A current module handbook, assessment brief, rubric, and marker guidance determine what a distinction requires in a particular task. Never infer a mark, weighting, criterion, or module rule merely from this page.
