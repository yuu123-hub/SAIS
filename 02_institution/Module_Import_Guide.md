# Module Profile Import Guide

Create `02_institution/modules/<module-code>/Module_Profile.md` only from official programme materials. Record source filename/URL, date received, and the exact wording of learning outcomes and assessment criteria where permitted.

Required fields: module code and title; academic year; learning outcomes; assessment type; weighting; due date; rubric; required referencing style; permitted AI use; required readings; lecturer/supervisor directions; unresolved questions.
