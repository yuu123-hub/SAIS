# Module Profile Import Guide

Create `02_institution/modules/<module-code>/Module_Profile.md` and `Module_Performance_Contract.md` only from official programme materials. Record source filename/URL, date received, and the exact wording of learning outcomes and assessment criteria where permitted.

Required fields: module code and title; academic year; learning outcomes; assessment type; weighting; due date; rubric; distinction descriptors; required referencing style; permitted AI use; required readings; lecturer/supervisor directions; career/portfolio opportunities; risk register; and unresolved questions.

Use `scripts/New-SAISModule.ps1` to create a consistent module scaffold. Store licensed or access-controlled originals in the generated `source_materials/` directory, which is ignored by Git. Register every source and superseded version in `Module_Source_Register.md`.
