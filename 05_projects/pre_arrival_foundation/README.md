# Pre-arrival Foundation

Use this project before enrolment. It is deliberately separate from future assessed projects.

- `materials/` — official programme documents, reading PDFs, and non-sensitive sources.
- `notes/` — working records created from SAIS templates.
- `private/` — personal or sensitive material; ignored by Git.

## First prompt

After placing a source in `materials/`, tell Codex:

> Use SAIS to analyse the source in `05_projects/pre_arrival_foundation/materials/`. Create a reading note, identify transferable MSc skills, and list any information that still needs official verification.
