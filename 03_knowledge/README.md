# Pre-arrival Knowledge Base

## Purpose

This directory provides compact learning foundations for the MSc before final module handbooks, reading lists, and assessment rules are available. It is a **learning aid**, not an institutional source, a substitute for a prescribed text, or a source of ready-to-submit claims.

## How to use it

1. Start with the Chinese plain-language explanation.
2. Explain the concept back in your own Chinese words and create a small example.
3. Read the English academic terms and sentence frames.
4. When a real assignment begins, verify the concept through original or current academic sources and record them in the relevant project.

## Knowledge layers

| Area | Contents | Status |
| --- | --- | --- |
| `foundations/` | Management and international-business concepts | General orientation; verify before citation |
| `research_methods/` | Research design and statistics foundations | General orientation; not a methods approval |
| `academic_skills/` | Criticality, vocabulary, and argument-building support | Transferable learning support |

## Boundary

This knowledge base does not define a module syllabus, assessment weighting, required theory, or a Sheffield marking rule. Official module material, the current assignment brief, rubric, and supervisor direction always take priority.
